Aqara Cameras

Gebruik de officiële Aqara Account Authorization API. Voor deze methode heb je geen OAuth Client Secret nodig en hoef je geen Aqara-wachtwoord in Homey op te slaan.

1. Aqara Developer-project

Dit is het App ID van je goedgekeurde project in Aqara Developer Platform.
De App Key hoort bij de Key ID en wordt gebruikt om API-requests te ondertekenen. Dit is niet hetzelfde als een OAuth Client Secret.
Deze drie waarden vind je in Project Management → Project Details → Key Management.
Waarom geen Client Secret?
De Aqara Account Authorization API gebruikt App ID + Key ID + App Key + request-signing. De OAuth Client Secret is alleen nodig voor Aqara OAuth 2.0.
